# Portal (M-237) — ONE domain: portal.ddvnguyen.com
Cloudflare: tunnel ingress `portal.ddvnguyen.com` -> `http://host.containers.internal:3720`, Access app "Portal" (Admin policy). No other hostnames were added.
- `portal-caddy` (:3720): serves the tab UI (`ui/_portal`), `/browser/` (virtual browser, server-side basic-auth header injected), `/_portal/api/*` (opener). Generated by `bin/portal-sync` into `routes/all.inc` (mode 0600, contains the browser password).
- `portal-browser` (podman, host network, Selkies websocket streaming): Chromium running on the server, so it opens real `http://127.0.0.1:<port>` sites. CDP on 127.0.0.1:9223.
- `portal-opener` (127.0.0.1:3735): UI click -> opens/activates a tab in that Chromium via CDP. Only ports in the allowlist (services.tsv + dynamic.tsv). Requires header `X-Portal: 1`.
- Allowlist: `services.tsv`; add `bin/portal-add <name> <port> [group] [title] [desc] [path]`, remove `bin/portal-rm <name>`. Dynamic ports: `portal-scan.timer` + `dynamic-rules.tsv`.
- **Ports (M-245): resolve every port with `bin/ports get <id> --port` (e.g. `bin/ports get dsh-x.web --port` → 3181) or `bin/ports list [--app X] [--json]` — never hard-code a port.** Registry: `ports.yaml` (static + dynamic-family rules), `ports.dynamic.json` (30s scan, generated), `ports.registered.json` + `bin/ports-api` (loopback :3725, token `.ports.token` 0600), drift: `bin/ports check`.
- **Leases (M-249): open any non-registered loopback port.** Page `https://portal.ddvnguyen.com/lease/` (search box; also a "Ports" tab). `bin/lease-api` (127.0.0.1:3726, `portal-lease.service`) creates a Muximux app `Lease :<port>` (proxy mode, `/proxy/lease-<port>/`) — M-246 proved Muximux adds proxied apps at runtime, so no dynamic Caddy routes. Lease lives while the session WebSocket is up (server-side protocol ping, `heartbeat_seconds`); grace 30s after it drops, hard cap 8h, numbers in `lease.yaml`. Deny list `ports-deny.yaml` (SSH, databases, Caddy admins, CDP, VNC, Muximux/portal/lease-api loops). Targets are 127.0.0.1 only — the host never comes from the request. Memory-only state: restart of `portal-lease` (or the portal) drops all leases; startup purge + `portal-muximux-sync` reconciliation remove stale `Lease :` tabs. Audit: `logs/lease-audit.jsonl`.
- Retired (see bin.v1-backup): per-service hostnames, the old per-lease `/proxy/lease-N/` path proxy (superseded by the service-worker port gateway `bin/portal-gw`, see docs/ADR-portal-gateway.md), Homepage.
- Secrets: browser/env (0600).

- Adding a service: see docs/ADDING-A-SERVICE.md. Design and decisions: docs/ADR-portal-gateway.md.
